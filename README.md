# Exercícios de Algoritmos

Repositório com resoluções de exercícios de algoritmos e estruturas de dados
(LeetCode e afins), usado como prática e como parte do portfólio.

Não é focado em uma linguagem específica — as soluções vão sendo adicionadas
em diferentes linguagens conforme o exercício é revisitado ou refeito.

## Estrutura

Uma pasta por linguagem, com um arquivo por exercício dentro. A explicação
da abordagem e da complexidade fica em comentários no topo de cada arquivo.

```
java/
├── TwoSum.java
└── ...
python/
└── ...
```
